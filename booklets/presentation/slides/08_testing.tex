\begin{frame}{Testing \& Verification}
\begin{itemize}
    \item \textbf{Unit Tests:} Core components like data parsers, geocoders, and the optimizer are tested individually.
    \item \textbf{Integration Verification:} Ensuring end-to-end flow from file upload to the final route generation.
    \item \textbf{Robustness:} 
        \begin{itemize}
            \item Clear error messages on invalid ERP uploads.
            \item Handled edge cases (e.g., missing addresses, missing API responses).
            \item Geographic fallbacks when standard routing fails.
        \end{itemize}
\end{itemize}
\end{frame}
