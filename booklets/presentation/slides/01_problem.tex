\begin{frame}{Business Problem}
\begin{itemize}
    \item \textbf{Context:} The project helps a federation of three companies plan visits for their sales representatives.
    \item \textbf{Data:} We start from an Excel file containing customers, delivery points, sales agents, and revenue data.
    \item \textbf{The Challenge:} Sales representatives have limited time. The problem is deciding \textbf{which customers to visit}, in \textbf{which order}, and on \textbf{which days}.
    \item \textbf{The Goal:} Cover as much relevant revenue as possible within the available working time.
    \item \textbf{What-if Analysis:} The user can easily compare different scenarios by changing the number of available days and the duration of each visit.
\end{itemize}
\end{frame}
